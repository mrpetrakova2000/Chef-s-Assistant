## Спецификации модулей: Chef's Assistant

### 1. Classifier Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Определение, относится ли запрос пользователя к кулинарной тематике |
| **Входные данные** | Текст запроса пользователя (строка, до 200 символов) |
| **Выходные данные** | `skip_execution` (boolean) |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **System Prompt** | Строгая инструкция классифицировать только кулинарные запросы |
| **Timeout** | 30 секунд |
| **Retry** | 2 попытки с экспоненциальной задержкой |
| **Fallback** | При недоступности LLM — считать запрос подходящим |

### 2. Planner Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Генерация структурированного списка ингредиентов для блюда |
| **Входные данные** | Текст запроса (string) |
| **Выходные данные** | `dish_name`, `portions`, `plan: [{name}]` |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **System Prompt** | Инструкция по формированию списка (только покупные продукты, без воды) |
| **Timeout** | 30 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Базовый список ингредиентов |
| **Валидация** | Проверка JSON, не более 20 ингредиентов |

### 3. Router Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Определение категории товара в конкретном магазине для ингредиента |
| **Входные данные** | Название ингредиента, название магазина, список доступных категорий |
| **Выходные данные** | `category_name`, `category_url` |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **System Prompt** | Инструкция по маппингу ингредиента на категорию |
| **Timeout** | 10 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Маппинг по ключевым словам, первая доступная категория |

### 4. Parser Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Парсинг товаров из категории магазина |
| **Входные данные** | Название магазина, URL категории |
| **Выходные данные** | Список товаров: `[{link, description, price, store}]` |
| **Метод** | Selenium (undetected-chromedriver) + BeautifulSoup |
| **Timeout** | 30 секунд на страницу |
| **Пагинация** | До 5 страниц |
| **Кэширование** | Ключ: `{store}:{category_url}`, TTL 6 часов |
| **Антидетект** | Случайный User-Agent, скрытие webdriver |

### 5. Selector Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Выбор наиболее релевантного товара из списка |
| **Входные данные** | Название ингредиента, список товаров, контекст блюда |
| **Выходные данные** | Выбранный товар или None |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **System Prompt** | Инструкция по выбору товара (соответствие, цена) |
| **Timeout** | 10 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Первый товар из списка |

### 6. Comparator Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Сравнение предложений из разных магазинов |
| **Входные данные** | Название ингредиента, список предложений |
| **Выходные данные** | Оптимальное предложение |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **System Prompt** | Инструкция по сравнению цен и релевантности |
| **Timeout** | 10 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Самое дешевое предложение |

### 7. Reporter Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Формирование структурированного отчета |
| **Входные данные** | Название блюда, порции, результаты поиска |
| **Выходные данные** | Markdown текст, общая сумма |
| **Модель LLM** | Mistral (mistral-large-latest) |
| **Формат отчета** | Markdown с эмодзи, найденные/ненайденные товары, ссылки |
| **Timeout** | 5 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Простой текстовый отчет |

### 8. Cache Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Кэширование результатов парсинга и LLM-ответов |
| **Структура** | In-memory dictionary с TTL |
| **Ключ продуктов** | `{store}:{category_url}` |
| **Ключ категорий** | `{store}` |
| **Ключ LLM** | MD5 промпта |
| **TTL** | 6 часов |
| **Очистка** | Автоматическая по TTL, ручная через API |

### 9. API Gateway Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Входная точка HTTP-запросов |
| **Технология** | FastAPI |
| **Endpoint** | `POST /query` — обработка запроса |
| **Health check** | `GET /health` |
| **Статус** | `GET /status` — статистика кэша |
| **Очистка кэша** | `POST /clear-cache` |
| **Формат запроса** | `{"question": "Салат Цезарь на 4 порции"}` |
| **Формат ответа** | `{"success": bool, "dish_name": str, "ingredients": [...], "total_price": float, "markdown_text": str, "elapsed_seconds": float, "stats": {...}}` |
| **Валидация** | Длина запроса ≤ 200 символов |
| **Timeout** | 300 секунд |
