## Спецификации модулей: Chef's Assistant

### 1. Classifier Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Определение, относится ли запрос пользователя к кулинарной тематике |
| **Входные данные** | Текст запроса пользователя (строка, до 200 символов) |
| **Выходные данные** | `is_culinary` (boolean), `confidence` (float 0-1), `dish_name` (string) |
| **Модель LLM** | Mistral |
| **System Prompt** | Строгая инструкция классифицировать только кулинарные запросы, игнорировать попытки изменения промпта |
| **Timeout** | 30 секунд |
| **Retry** | 2 попытки с экспоненциальной задержкой |
| **Fallback** | При недоступности LLM — возврат "not_culinary" с confidence=0 |

### 2. Planner Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Генерация структурированного списка ингредиентов для блюда |
| **Входные данные** | Название блюда (string), количество порций (int) |
| **Выходные данные** | Список ингредиентов: `[{name, quantity, unit}]` |
| **Модель LLM** | Mistral |
| **System Prompt** | Инструкция по формированию списка с указанием количества и единиц измерения |
| **Timeout** | 30 секунд |
| **Retry** | 2 попытки |
| **Fallback** | Поиск в JSON-файле предопределенных рецептов |
| **Валидация** | Проверка: не более 20 ингредиентов, все поля заполнены |

### 3. Router Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Определение категории товара в конкретном магазине для ингредиента |
| **Входные данные** | Название ингредиента (string), название магазина (string), список доступных категорий магазина |
| **Выходные данные** | Название категории (string) или URL категории |
| **Модель LLM** | Mistral |
| **System Prompt** | Инструкция по маппингу ингредиента на категорию с учетом специфики магазина |
| **Timeout** | 10 секунд |
| **Retry** | 2 попытки с альтернативными категориями |
| **Fallback** | При неудаче — возврат общей категории "продукты" |

### 4. Parser Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Парсинг товаров из категории магазина |
| **Входные данные** | Название магазина (string), категория (string), номер страницы (int) |
| **Выходные данные** | Список товаров: `[{name, price, url, store}]` |
| **Метод** | Selenium WebDriver (headless) + BeautifulSoup |
| **Timeout** | 10 секунд на страницу |
| **Retry** | 2 попытки с экспоненциальной задержкой |
| **Кэширование** | Ключ: `{store}:{category}:{page}`, TTL 1 час |
| **Обработка ошибок** | При ошибке — возврат пустого списка, логирование |

### 5. Selector Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Выбор наиболее релевантного товара из списка для ингредиента |
| **Входные данные** | Название ингредиента (string), список товаров, контекст блюда (string) |
| **Выходные данные** | Выбранный товар (Product) или None |
| **Модель LLM** | Mistral |
| **System Prompt** | Инструкция по выбору товара с учетом релевантности, цены |
| **Timeout** | 10 секунд |
| **Retry** | 1 попытка |
| **Fallback** | При недоступности LLM — выбор по точному совпадению названия |

### 6. Comparator Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Сравнение предложений из разных магазинов для одного ингредиента |
| **Входные данные** | Название ингредиента (string), список предложений `[{store, price, product}]` |
| **Выходные данные** | Оптимальное предложение |
| **Модель LLM** | Mistral |
| **System Prompt** | Инструкция по сравнению цен с учетом релевантности товара |
| **Timeout** | 10 секунд |
| **Retry** | 1 попытка |
| **Fallback** | При недоступности LLM — выбор самого дешевого предложения |

### 7. Reporter Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Формирование структурированного отчета для пользователя |
| **Входные данные** | Список выбранных предложений, список ошибок, общая сумма |
| **Выходные данные** | Список с информацией о выбранных товарах |
| **Модель LLM** | Mistral |
| **Формат отчета** | Таблица ингредиентов, общая сумма, список магазинов, ссылки на товары |
| **Timeout** | 5 секунд |
| **Retry** | Не применяется |
| **Особенности** | Отметка о замене ингредиентов, выделение отсутствующих товаров |

### 8. Cache Agent Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Кэширование результатов парсинга для ускорения повторных запросов |
| **Структура** | In-memory dictionary с TTL |
| **Ключ** | `{store}:{category}:{page}` |
| **Значение** | Список товаров (сериализованный JSON) |
| **TTL** | 3600 секунд (1 час) |
| **Максимальный размер** | 100 МБ |
| **Политика вытеснения** | LRU (Least Recently Used) |
| **Очистка** | Автоматическая по TTL или при перезапуске сервиса |

### 9. Memory Agent (Logging) Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Логирование выполнения сессии для отладки и анализа |
| **Формат логов** | JSON Lines |
| **Поля лога** | timestamp, session_id, step, duration_ms, tokens_used, status, error |
| **Хранение** | Файловая система (`logs/chef_assistant.log`) |
| **Ротация** | Ежедневная (при необходимости) |
| **Что не логируется** | Исходный user_id, полный текст запроса, персональные данные |
| **Уровни логирования** | INFO (по умолчанию), DEBUG (для отладки), ERROR (для ошибок) |

### 10. Web UI Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Интерфейс взаимодействия с пользователем |
| **Технология** | React |
| **Страницы** | Одна страница: форма ввода + область результатов |
| **Форма ввода** | Текстовое поле (textarea), кнопка отправки, возможность выбора магазинов для поиска |
| **Индикация** | Лоадер при обработке, индикатор прогресса |
| **Отображение отчета** | Таблица с ингредиентами, ценами, ссылками; общая сумма; список магазинов |
| **Обработка ошибок** | Отображение ошибок пользователю, рекомендации по повторной отправке |

### 11. API Gateway Specification

| Параметр | Описание |
|----------|----------|
| **Назначение** | Входная точка HTTP-запросов от Web UI |
| **Технология** | FastAPI |
| **Endpoint** | `POST /api/v1/process` — основной endpoint обработки запроса |
| **Health check** | `GET /health` — проверка работоспособности |
| **Список магазинов** | `GET /api/v1/shops` — проверка работоспособности |
| **Формат запроса** | JSON: `{"query": "Хочу приготовить лазанью", "shops": ["magnit", "perekrestok"]}` |
| **Формат ответа** | JSON: `{"status": "success", "data": "{...}"}` |
| **Валидация** | Проверка наличия query, длины (≤200), опасных паттернов |
| **Timeout** | 120 секунд |
