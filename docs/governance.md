# Governance & Risk Register

## Risk Register

| Риск | Вероятность/Влияние | Детект | Защита | Остаточный риск |
|------|---------------------|--------|--------|-----------------|
| **Некорректная классификация запроса** | Средняя / Высокое | Логи показывают ложные срабатывания | Четкий system prompt с примерами; fallback на обработку при недоступности LLM | Несколько запросов в день могут быть неверно классифицированы |
| **LLM галлюцинирует ингредиенты** | Средняя / Среднее | Несоответствие известным рецептам | Валидация JSON; промпт с правилами (только покупные продукты, без воды); fallback на базовый список | Редкие блюда могут содержать неточности |
| **Неверный маппинг категории** | Высокая / Среднее | Продукты не найдены в указанной категории | Fallback-маппинг по ключевым словам; специальные правила для яиц, молочки, масел; кэширование успешных маппингов | ~10% ингредиентов могут маппиться неоптимально |
| **Отказ API магазина / блокировка парсинга** | Средняя / Высокое | Таймауты, коды 5xx, 429, пустые ответы | Graceful degradation (пропустить магазин); undetected-chromedriver с антидетектом; случайные User-Agent; задержки между запросами | Увеличение времени ответа или неполные результаты |
| **Prompt Injection** | Низкая / Высокое | Нестандартные паттерны в логах | Валидация ввода (длина ≤ 200); изоляция system prompt; output filtering | Система может отказать легитимному запросу |
| **Превышение бюджета LLM** | Низкая / Среднее | cost_per_query > threshold | Кэширование LLM-ответов (MD5 промпта); retry с экспоненциальной задержкой; fallback-стратегии | Сложные запросы могут обрабатываться дольше |
| **Небезопасные ссылки** | Низкая / Среднее | URL ведут на подозрительные домены | Белый список доменов магазинов; ссылки только из спарсенных данных | Нельзя добавить магазин без проверки |
| **Бесконечный цикл обработки** | Низкая / Высокое | Время выполнения > timeout | Ограничение по страницам (max 5); глобальный timeout 300 сек; счетчики ингредиентов и магазинов | Система может прервать сложный запрос |
| **Утечка памяти между запросами** | Средняя / Высокое | Рост потребления RAM | Очистка состояния перед каждым запросом; gc.collect() после обработки; atexit cleanup | При интенсивной нагрузке возможны утечки |
| **Отказ LLM API (503, 429)** | Средняя / Высокое | Ошибки при вызове API | Retry до 3 раз с экспоненциальной задержкой; fallback-ответы для каждого агента | Временная недоступность сервиса |

## Политика логов и работы с персональными данными

### Персональные данные
В рамках PoC мы минимизируем сбор персональных данных:

| Тип данных | Сбор | Хранение | Обоснование |
|------------|------|----------|-------------|
| User ID | Нет | - | Не требуется для PoC |
| Имя пользователя | Нет | - | Не требуется |
| Геолокация | Нет | - | Не требуется |
| История покупок | Нет | - | Out of scope |
| Текст запроса | Да (в памяти сессии) | Только в рамках запроса | Обработка запроса |
| Результаты поиска | Да (в памяти сессии) | Только в рамках запроса | Формирование ответа |

**Принципы работы с данными:**
1. **Минимизация:** Собираем только необходимое для обработки запроса
2. **Временное хранение:** Данные живут только в рамках одной сессии запроса
3. **Очистка:** Состояние полностью очищается после каждого запроса
4. **Отсутствие персистентности:** Пользовательские данные не сохраняются на диск

### Что логируем:
- timestamp запроса
- вызовы агентов и их результаты
- список обработанных магазинов и найденных ингредиентов
- время выполнения запроса
- ошибки и исключения

### Что НЕ логируем:
- персональные данные пользователя
- полные тексты запросов в персистентном хранилище
- точные адреса или контактные данные

### Валидация ввода

```python
def validate_user_input(query: str) -> bool:
    # Проверка длины
    if len(query) > 200:
        return False
    
    # Проверка на опасные паттерны
    dangerous = ["ignore previous", "system prompt", "you are now", "sudo"]
    for pattern in dangerous:
        if pattern in query.lower():
            return False
    
    return True
```

## Обработка ошибок

| Тип ошибки | Обработка | Fallback |
|------------|-----------|----------|
| LLM API недоступен | Retry 3 раза | Предустановленный ответ |
| Магазин не отвечает | Пропуск магазина | Пустой список товаров |
| Категория не определена | Fallback-маппинг | Первая доступная категория |
| Товар не выбран | Fallback на первый | Первый товар из списка |
| Ошибка парсинга | Возврат пустого списка | Логирование ошибки |
